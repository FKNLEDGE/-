# 14.8 · 课题推演沙盘：从一个固碳增产问题走到结论（全库综合实战）

> 💡 **思路 & 可能性**：这是全库的**"毕业实战"**——拿一个**具体**的固碳增产问题，从 科学问题 → 假说 → 设计 → 测什么 → 分析 → 解读 → 结论 **完整走一遍**，并在**每一步标出"用到库里哪个模块、哪条护栏"**。
>
> 它和 [14.4 研究设计与分析方案](./04-研究设计与分析方案.md) 的区别：14.4 是**可照抄的方案模板**；这一篇是**一次"带决策和判断的活推演"**——示范遇到真问题时，这套库怎么串成一条**有判断力的决策链**。纯推演，不落操作命令。

---

## 🎯 选题（一个具体、真实的问题）

> **"在我这片农田，长期'有机无机配施'比单施化肥，能不能**既增产又固碳**？微生物机制是什么？"**

这是你方向上最典型的问题。下面一步步推演。

---

## 第 0 步 · 先问"这问题问得好吗"（框架5：假说 vs 数据驱动）

不要一上来就测序。先把大问题**拆成可检验的假说**：

- **H1（固碳链）**：配施 → C:N:P 更平衡 → 微生物 CUE 更高 → 更多坏死体 → 更多 MAOC（[14.5](./05-化学计量比视角-固碳与增产.md)、[14.3](./03-有机碳固存与激发效应.md)）。
- **H2（增产链）**：配施 → 养分循环功能基因/菌群改变 → 养分供给改善 → 增产。
- **定性**：这是**"机制 + 效应"型**问题 → 证据要求高（[框架1](../03-思维框架.md) 先定证据天花板：要谈"固碳"就得有**通量级**证据，不能只停在基因）。

> 🔑 **这一步就决定了成败**：问题拆得清，后面每一步才有靶子。

---

## 第 1 步 · 研究设计（框架6 + 14.4 + 15.1）

| 设计要素 | 决策 | 护栏/来源 |
| --- | --- | --- |
| **处理** | CK / 化肥NPK / 有机肥 / 配施（最好带梯度） | 框架6 对照 |
| **重复** | ≥3–4 个**真**生物学重复（警惕伪重复） | 框架6；根际判读卡4 |
| **试验** | 优先**长期定位试验**（固碳是慢变量，短期看不出） | 固碳争议·时间尺度 |
| **采样深度** | **分层**（0–20/20–40/更深）+ **等质量核算** | ⚠️固碳判读卡2"只测表土"坑 |
| **保存** | 立刻 −80℃/液氮 | 模型4 |
| **元数据** | 按 **MIxS** 记（经纬/pH/容重/施肥史/气候） | 15.1 |
| **质控对照** | 阴性对照（kitome）+ 若做绝对定量加内标/mock | 框架6；难点08.1 |
| **混杂** | 处理打散到批次、地块随机化 | 框架6 批次效应 |

---

## 第 2 步 · 测什么（组学阶梯，按问题选层 —— 不是越多越好）

```
地基（必测）  宏基因组（鸟枪）── 功能基因“潜力”：CAZy、养分获取基因、CUE相关  （模型2、14.1）
   │  但“潜力”到不了“固碳量”，所以要往“通量端”加：
   ├─ 通量端（固碳必加）  SOC组分(MAOC/POC物理分组) + 坏死体(氨基糖) + CUE(¹⁸O*) + ¹³C同位素(因果)
   └─ 活性端（可选加强）  宏转录组 / 代谢组（看“在表达/真产物”）           （11.3、11.6）
```
> ⚠️ `*` CUE 的 ¹⁸O 法在干土有偏差（[固碳争议3](./07-固碳前沿争议.md)）——记录土壤干湿、慎比绝对值。
>
> 🔑 一句话：**宏基因组管"机制潜力"，固碳量必须配实测（[框架3](../03-思维框架.md)）。** 这是整个课题最容易被审稿人攻击的点。

---

## 第 3 步 · 分析（专挑统计坑避）

1. **组成型**：CLR 或绝对定量，别拿相对丰度直接比（[模型14](../02-必学模型/03-多样性与统计模型.md)、难点08.1）。
2. **群落**：α/β 多样性 + **PERMANOVA**（别只看 PCoA 分开了 → 模型12）。
3. **差异基因**：ALDEx2 / ANCOM-BC 类（内置 CLR）。
4. **功能基因"成套 + 比值"读**：算"碳降解(CAZy) : 养分获取(phoD/pstS/N获取)"比值（[14.5](./05-化学计量比视角-固碳与增产.md)）——别单基因下结论（⚠️养分判读卡1）。
5. **关联建模**：基因 ↔ CUE ↔ MAOC ↔ 产量 用 **SEM / path analysis**（14.5）。
6. **relic DNA 警觉**：施有机肥后死菌多，测到≠活跃（难点08.5）——差异大处考虑配 RNA。
7. **多重检验校正**（框架5）。

---

## 第 4 步 · 解读（逐条守护栏）

| 你想说 | 护栏拦一下 | 该怎么说 |
| --- | --- | --- |
| "配施提升了固碳功能" | 潜力≠活性≠通量（框架3） | "改变了固碳相关基因**潜力**；MAOC（若实测）也升高" |
| "配施**导致**固碳" | 相关≠因果（框架7） | 配施与 MAOC **相关**；因果需 ¹³C/操控 |
| "配施**通过提高 CUE**固碳" | 机制归因要分离（争议1/2） | 需 CUE 实测 + 坏死体 + 排除矿物保护等替代解释 |
| "这结论普遍适用" | 尺度（框架1） | 限本土壤/体系；跨体系需多点验证 |

---

## 第 5 步 · 下结论（给每句话标"可信度等级"，呼应 12.5 判读）

- ✅ **能稳说**：配施可重复地**改变了碳/养分循环功能基因的潜力结构**；（若实测）**MAOC 与产量同时升高**，且与计量平衡/CUE **相关**。
- ⚠️ **要谨慎**："配施**通过** CUE/坏死体路径**驱动**固碳"——这是**机制声明**，需同位素 + 贡献分解证据撑（[固碳争议2](./07-固碳前沿争议.md)）。
- ⛔ **不能说**：外推到"所有土壤/全球都该配施固碳"。

---

## 第 6 步 · 投稿前自审（把 [12.5](../12-自测与练习/05-论文判读实战.md) 的"10 问清单"对自己用一遍）

> **你写论文前，先用判读别人论文的那把尺子量自己。** 自己先挑出"潜力当通量、组成型没校正、只测表土、相关说成因果"——审稿人就挑不出大坑了。**会判读别人 = 会自审自己。**

## 🧭 一张图：全库如何在这一个课题里串起来

```
科学问题(框架5)
   │ 拆假说、定证据天花板(框架1)
   ▼
设计(框架6 · 14.4 · 元数据15.1 · 避伪重复/控批次/分层采样)
   │
   ▼
测什么(组学阶梯：宏基因组=潜力 + 通量端SOC组分/坏死体/CUE/¹³C + 活性端可选)
   │
   ▼
分析(组成型模型14 · 排序模型12 · 成套比值14.5 · relic警觉08.5 · 多重校正框架5)
   │
   ▼
解读(护栏：潜力≠通量框架3 · 相关≠因果框架7 · 机制归因争议1/2 · 尺度框架1)
   │
   ▼
结论(分可信度等级) ──► 投稿前用"10问清单"自审(12.5)
```

> ✅ **本篇要义**：真正的科研能力，不是记住多少知识，而是把知识在**一个真问题**上**串成一条带判断的决策链**。这篇就是那条链的示范。**换一个问题（N₂O 减排、盐碱改良、秸秆固碳…），把每一步的"选择 + 护栏"重走一遍即可。** 这，就是这个库要交到你手里的最终能力。
