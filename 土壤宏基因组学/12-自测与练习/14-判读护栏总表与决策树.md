## 一、判读总决策树（拿到论文先走一遍）

```
拿到一篇论文
 │
 ├─① 哪类研究？证据天花板在哪？(框架1/5)
 │     描述/相关型 → 别苛求因果；机制/因果型 → 要够格证据
 │
 ├─② 测的是哪一层？  测到 → 活的 → 有基因 → 在转录 → 有产物/通量
 │     测到DNA？   → 可能是死菌(relic, 08.5)
 │     有基因？    → 潜力≠活性≠通量(框架3)  ★最常踩
 │     说活性/通量？→ 有RNA/蛋白/同位素吗？
 │
 ├─③ 数据处理对吗？
 │     相对丰度？  → 组成型，CLR/绝对定量了吗(模型14)
 │     marker选全？(nosZ分clade…) 数据库够吗？
 │     测够深？抽平？多重校正？(模型3/框架5)
 │
 ├─④ 归因站得住吗？
 │     相关还是因果？方向定得了？(框架7)
 │     单基因 还是 成套+比值？(净过程要两端)
 │     效应 还是 机制？(机制要排除替代解释)
 │     共现 ≠ 共载 ≠ 互作 ≠ 同宿主
 │
 ├─⑤ 设计有硬伤吗？
 │     真重复？伪重复？对照(阴性+阳性mock)？批次？(框架6)
 │     采样：深度/边界？等质量？操作定义(根际)？元数据(MIxS)？
 │
 └─⑥ 外推合理吗？
       尺度(团聚体/田块/区域/全球)？受控≠真实？平均≠普适？
       短期≠长期(会适应)？投影≠实测？空间换时间？
 →→ 给每个结论标：✅可信 / ⚠️打折 / 📋必查全文
```

## 二、护栏全集（按层分类 + 出处卡）

### A · 测量层：测到了什么？
| 护栏 | 一句话 | 例证 |
| --- | --- | --- |
| **潜力≠活性≠通量** | 有基因≠在表达≠真干了多少 | 12.5/养分/碳氮 |
| **测到≠活菌** | relic DNA / 休眠 | 08.5 / ARG卡2 |
| **检出≠表型** | 抗性基因≠耐药/修复表型 | ARG / 逆境卡1 |
| **相对≠绝对** | 组成型，比例≠数量 | 08.1 / 养分卡 |
| **估算≠实测** | 坏死体占比靠换算系数 | 固碳卡3 |
| **携带≠表达** | 病毒 AMG | 病毒卡1 |
| **净通量=产−消** | 只看一端必错（nosZ、mcrA/pmoA 比值） | 温室卡1/3 |

## 三、也要会认"好"：4 个正面范例

判读不只挑坑——这些是**证据够格**的范式，看到要会欣赏、会模仿：

| 范例 | 强在哪 | 出处 |
| --- | --- | --- |
| N₂O 的 pH 因果 | 多组学 + 反应动力学 + 操控变量 | 温室卡2 |
| 活跃抗性组 | 单细胞同位素 + 靶向（测"活的、谁携带"） | ARG卡2 |
| N 循环转录响应 | 测**转录**抓动态耦合 | 碳氮卡2 |
| genome-resolved | 归到 MAG，说清"是谁" | 磷/逆境卡 |

> 🔑 好研究的共性：**往"活性/通量/因果/是谁"多走一步**，并配**操控变量或同位素**。

## 四、一句话总纲

> **判读 = 把每个结论翻译成"能信几分" = 沿着"测量 → 归因 → 设计 → 外推"四问，给每句话标 ✅/⚠️/📋。**

工具会换代、热点会轮转，但这张护栏表不会过时。它是你**读论文、做研究、不被忽悠**的随身尺——也是这个库从第一性原理到判读实战，最终想交到你手里的**那一种能力**。
