# 00 · 命令行/终端零基础扫盲（连终端都没用过，先看这篇）

> ⚠️ **如果你从没用过"黑窗口"敲命令，请先读这一篇，再去读第 4 章。** 第 4 章默认你已经会用终端了，但很多人就卡在"终端怎么打开""为什么我一敲就报错"——这一篇把这层窗户纸捅破。
> 读完你会发现：终端没什么可怕的，**就是一个用打字代替点鼠标的文件管理器**。

---

## 一、终端是什么？别被"黑客电影"吓到

终端（也叫命令行、命令提示符、Terminal、Shell）就是那个**黑底白字、能打字的窗口**。

> 🔑 一句话：**平时你用鼠标"双击文件夹、拖动文件"，终端是用"打字"做同样的事。** 仅此而已，没有魔法。

为什么程序员爱用它？因为**打字比点鼠标快、能精确、能自动化**。但对你来说，现在只要会几个最基本的就够了。

### 先破除三个恐惧

1. **"敲错了会不会把电脑搞坏？"** —— 不会。你现在要学的命令（看看在哪、列文件、换目录）都是**只看不改**的，最多报个错，电脑毫发无伤。
2. **"报错了是不是我太菜？"** —— 不是。报错是终端在**和你说话、告诉你哪里不对**，看不懂就把那行红字复制去搜。程序员每天都在看报错。
3. **"是不是要背很多命令？"** —— 不用。日常就 `pwd`、`ls`、`cd` 三个保命命令 + 第 4 章那 7 条 Git 命令。

## 二、怎么打开终端

### Windows：用 Git Bash（装完 Git 就有，见第 02 章）

> ⚠️ Windows 自带的"命令提示符 cmd"和"PowerShell"也能用，但**本教程统一用 Git Bash**——它和 Mac/Linux 的命令一致，教程里的命令能直接照抄，不容易出岔子。

打开方式（任选）：
- **开始菜单**搜 `Git Bash`，点开。
- 或在**任意文件夹空白处点右键** → 选 **"Git Bash Here"**（或"Open Git Bash here"）→ 直接在这个文件夹打开终端，**超方便**（省去自己 cd 过去）。

### macOS：用"终端"

- 按 `Command(⌘) + 空格` 打开聚焦搜索，输 `Terminal`（终端），回车。
- 或：访达 → 应用程序 → 实用工具 → 终端。

### 打开后你看到的画面（提示符）

会看到类似这样的一行，末尾有个闪烁光标，等你打字：

```
用户名@电脑名 MINGW64 ~/Desktop
$
```

或 Mac 上：

```
电脑名:Desktop 用户名$
```

**这串叫"提示符（prompt）"**，它在告诉你：你是谁、在哪台机器、**当前在哪个文件夹**（上面例子是 `Desktop`）。

> 🚨🚨 **极其重要、小白头号翻车点**：那个 **`$`（Mac/Git Bash）或 `#`** 是提示符的一部分，**是终端自动显示的，不是让你敲的！**
> 教程里写 `$ git status`，你只需要敲 **`git status`**，**千万别把开头的 `$` 也打进去**，否则必报错 `$: command not found`。本教程的代码块里一般不写 `$`，但你在网上看别的教程要小心这点。

## 三、三个保命命令：我在哪、这有啥、去哪儿

终端里你"看不到文件夹的样子"，全靠这三个命令"摸索"。用逛商场类比：

| 命令 | 全称记忆 | 作用 | 商场类比 |
| --- | --- | --- | --- |
| `pwd` | **p**rint **w**orking **d**irectory | **我现在在哪个文件夹？** | "我在商场几楼哪个区？" |
| `ls` | **l**i**s**t | **当前文件夹里有啥？** | "这层楼有哪些店？" |
| `cd` | **c**hange **d**irectory | **进入/切换到某个文件夹** | "走进某家店 / 上下楼" |

### 1. `pwd`——我在哪

敲 `pwd` 回车，它打印出你当前所在文件夹的**完整路径**：

```
/c/Users/xiaoming/Desktop
```

（意思是：C 盘 → Users → xiaoming → Desktop 文件夹里）

### 2. `ls`——这儿有啥

敲 `ls` 回车，列出当前文件夹里的所有文件和子文件夹：

```
my-notes    照片    简历.docx    日记.md
```

> 💡 想看更详细（带大小、日期）：`ls -l`；想连隐藏文件（如 `.git`、`.gitignore`，名字以点开头的）一起看：`ls -a`。

### 3. `cd`——去哪儿

这是用得最多的。几种用法：

```bash
cd my-notes        # 进入当前文件夹下名叫 my-notes 的子文件夹
cd ..              # 返回上一级文件夹（退一层，超常用！）
cd ~               # 直接回到"家目录"（你的用户主文件夹）
cd                 # 不带任何东西，效果同 cd ~，也是回家
```

> 📌 敲完 `cd` 之后，**用 `pwd` 确认一下你到没到对地方**，或者直接看提示符末尾的文件夹名变了没。这个"敲 cd → 看 pwd 确认"的习惯能帮你不迷路。

### 实战：从桌面走进项目文件夹（第 4 章的前置动作）

第 4 章让你"cd 到项目文件夹再敲 git 命令"，完整过程是这样的：

```bash
pwd                # ① 先看看我在哪。假设输出 /c/Users/xiaoming
cd Desktop         # ② 进入桌面
ls                 # ③ 看看桌面有啥，确认能看到 my-notes 这个文件夹
cd my-notes        # ④ 进入项目文件夹
pwd                # ⑤ 确认：输出末尾应该是 .../Desktop/my-notes，到位！
```

到这一步，你就站在项目里了，可以开始敲 `git status` 等命令了。

## 四、四个让你飞起来的神技（强烈建议练成肌肉记忆）

### 神技 1：Tab 键自动补全（最重要！）

敲文件夹/文件名敲一半，按 **`Tab` 键**，终端会自动帮你补全剩下的：

```
cd my-no   →（按 Tab）→   cd my-notes
```

> 🔑 **好处**：①打字快；②**不会拼错**（补全出来的一定是真实存在的）；③名字里有空格、中文也不怕。**养成"打几个字母就按 Tab"的习惯**，能避免大量"文件不存在"的错。如果按 Tab 没反应，可能是有多个同名开头，再按一下会列出所有候选。

### 神技 2：上方向键 ↑ 翻历史命令

按键盘 **`↑`（上箭头）**，能调出你**刚才敲过的命令**，不用重打。一直按往上翻历史。改个小地方再回车，效率翻倍。

### 神技 3：在终端里复制粘贴（和别处不一样！）

终端里 `Ctrl+C` **不是复制**（它是"中断命令"，见下），所以粘贴方式特殊：

| 系统 | 复制 | 粘贴 |
| --- | --- | --- |
| **Git Bash (Windows)** | 选中文字即自动复制，或 `Ctrl+Insert` | **右键** 或 `Shift+Insert` |
| **Windows Terminal/PowerShell** | `Ctrl+C` | `Ctrl+V` 或右键 |
| **macOS 终端** | `Cmd+C` | `Cmd+V` |

> ⚠️ 从教程/网页复制命令粘贴时，**别把开头的 `$` 也复制进去**（见上文头号翻车点）。

### 神技 4：`Ctrl + C` 是"急刹车"

如果一个命令卡住了、或者你想取消正在输入的命令，按 **`Ctrl + C`** 强行中断它，回到能输入的状态。**卡住别慌，先按 Ctrl+C。**

> 另一个常见情况：屏幕被一堆内容占满、底部出现 `:` 或高亮（这是在"分页查看"，比如 `git log`）——按 **`q`** 键退出。

## 五、路径：`/`、`~`、`.`、`..` 是什么意思

命令里经常出现这些符号，先混个脸熟（第 16 章还会细讲）：

| 符号 | 念作 | 意思 | 例子 |
| --- | --- | --- | --- |
| `/` | 斜杠 | 分隔文件夹层级 | `Desktop/my-notes` = 桌面里的 my-notes |
| `~` | 波浪号 | 你的"家目录"（用户主文件夹） | `cd ~` = 回家 |
| `.` | 一个点 | **当前**这个文件夹 | `git add .` = 加当前文件夹所有改动 |
| `..` | 两个点 | **上一级**文件夹 | `cd ..` = 退到上一层 |

**绝对路径 vs 相对路径**（理解就好）：

- **绝对路径**：从根开始写全，像写完整地址。`/c/Users/xiaoming/Desktop/my-notes`
- **相对路径**：从"我现在在哪"出发。我在 Desktop，那 `my-notes` 就指 `Desktop/my-notes`。

> 💡 **Windows 懒人神技**：把一个文件夹**直接拖进 Git Bash 窗口**，它会自动把那个文件夹的完整路径打出来！配合 `cd ` 用（注意 cd 后留个空格再拖）：先打 `cd `，再把文件夹拖进去，回车，就进去了，完全不用手打路径。

## 六、敲命令的几条规矩（避开 90% 的低级报错）

1. **区分大小写**（尤其 Mac/Linux）：`MyNotes` 和 `mynotes` 是两个不同的东西。
2. **命令和参数之间用空格隔开**：`cd my-notes` 中间那个空格不能少，也不能多打。
3. **文件名带空格要加引号**：文件夹叫 `my notes`（中间有空格），要写 `cd "my notes"`，否则终端以为是两个东西。**所以建议给文件/文件夹起名时别用空格，用 `-` 或 `_` 代替。**
4. **中文路径一般没问题**，但偶尔有工具不认，**初学建议项目名、文件夹名尽量用英文**，省心。
5. **看不懂的报错**：把那行英文复制下来直接搜，或问 AI，这是标准操作。

### 几条小白常踩的报错

| 报错 | 原因 | 解法 |
| --- | --- | --- |
| `command not found` | 命令拼错了，或把开头的 `$` 也敲了进去 | 检查拼写；别敲 `$` |
| `No such file or directory` | 文件夹/文件名打错了，或你不在那个位置 | 用 `ls` 看看到底有啥、用 `pwd` 确认位置、用 `Tab` 补全 |
| `Permission denied` | 没权限 | 大多数情况换个你自己的文件夹操作即可 |
