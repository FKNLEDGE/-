# 31 · 延伸资源精选：站在巨人肩上（不重复造轮子）

> 这套教程不打算、也没必要把所有东西都自己写一遍。外面有很多**做得极好、且免费**的资源——有的能"玩着学"，有的是官方圣经，有的专治"我搞砸了怎么办"。
> 这一篇**择优收编**：每个资源告诉你**它是什么、中文友好吗、什么时候该用它而不是自己啃、配合本教程哪一章**。把它当你的"资源地图"。

> 🧭 标注说明：🇨🇳=中文原生/有中文　🌐=英文为主　⭐=强烈推荐先用

> 🔗 **链接状态与使用说明（重要，先读）**：下列资源均在 **2026 年 6 月**通过联网搜索逐一确认**在线、内容相符**。但第三方网站会改版或迁移——**哪个链接打不开别慌：直接搜它的"名字"**（如搜「Learn Git Branching」「Pro Git 中文」「廖雪峰 Git」），**名字比网址稳定得多**，几乎一定找得到。
> - **官方站极稳定**：git-scm.com、github.com 系、semver.org、atlassian.com。
> - **少数站会拦自动程序**（如 [dangitgit.com](https://dangitgit.com/)、[conventionalcommits.org](https://www.conventionalcommits.org/)）：用**浏览器**能正常打开，只是脚本访问会被挡。
> - **国内访问**：github 系/官方文档偶尔慢；中文站（廖雪峰、菜鸟、阮一峰、semver 中文）更稳，卡了可先用 [Gitee](https://gitee.com)。

## 七、📺 视频教程（爱看视频的人）

文字看不下去？B 站有大量免费中文视频。**怎么挑**：认准**近 1–2 年、播放量高、评论好**的（GitHub 界面会改版，太老的视频对不上）。

- 在 **B 站搜**：`尚硅谷 Git&GitHub`、`黑马程序员 Git`、`1小时玩转Git Github`、`Github 新手够用指南`。

> ⚠️ 视频的弱点：**会过时**（UI 改版、命令演示用的旧界面）。所以**概念听视频、操作以官方最新和本教程为准**。

## 💡 用好外部资源的 4 条原则

1. **别贪多**。挑 **1 个主线**（本教程或廖雪峰）+ **1 个互动**（Learn Git Branching）+ **官方文档当词典**，足够了。同时开十个教程只会让你焦虑。
2. **互动 > 视频 > 纯文字**（对记命令而言）。能玩的优先玩。
3. **认准时效**。Git 命令几十年不变，但 **GitHub 网页和工具界面常改版**——UI 类教程认准新的，概念类看老的没问题。
4. **国内访问**：github.com / 官方文档 / ohshitgit 等有时慢；**中文站（廖雪峰、菜鸟、阮一峰、semver 中文）更稳**，练手卡了可先用 [Gitee](https://gitee.com)。

## 🙏 本教程的定位（我们补了别人没做好的那块）

诚实地说，上面很多资源在各自领域比我们更权威。**那我们的价值是什么？**

- **给"真·零基础"补最前面那一截**：别人默认你会用终端、看得懂英文报错、知道符号啥意思；我们从 [00 终端怎么打开](./00-命令行与终端零基础扫盲.md)、[16 符号黑话](./16-命令里的符号与黑话速查.md)、[18 英文报错直译](./18-英文界面与报错直译对照.md) 这些最基础的坎讲起。
- **中文、成体系、重思维**：[第一性原理](./24-第一性原理.md) + [20 模型](./25-必学模型/README.md) + [思维框架](./26-思维框架.md)，让你"懂"而不只是"会背"。
- **大量贴近生活的真实用途**：[10 个专题实战](./27-专题实战/README.md)（论文、小说、简历、打卡……）和 [真实案例库](./30-真实案例库.md)，不止讲代码。

> 🔑 **一句话**：把本教程当你的**中文主线和地图**，把这一篇的外部资源当**随取随用的弹药库**——哪块想深入或换个讲法，就去对应资源。学习不必从零自己趟，**站在巨人肩上**最聪明。
