## 🎯 怎么选你的第一个专题

```
你是学生/做研究        → 先做 #1 论文写作 或 #2 知识库
你在找工作/想有作品     → 先做 #4 在线简历 或 #7 博客
你想管理自己的生活/学习  → 先做 #5 待办管理 或 #6 习惯打卡
你想练团队/职场技能     → 先做 #8 团队协作
你想进开源世界         → 先做 #9 开源贡献
你是程序员/爱折腾       → 先做 #10 配置备份
你爱写作/创作          → 先做 #3 小说创作
```

> 💡 **建议**：先挑**一个你真的会持续用**的，把它做成你长期的真项目；其余的当扩展，想做了再做。**真实使用**才能把技能长进身体里。

## 📌 所有专题的通用心法

不管做哪个，都遵循这套（来自 [思维框架](../26-思维框架.md)）：

1. **先建仓库**，想清楚是 Public 还是 Private（涉及隐私的选私有）。
2. **想清楚文件夹结构**，用 README 当导航首页。
3. **小步提交**，每次 commit 说清做了什么。
4. **拿不准的改动开分支**，重要的项目走 PR。
5. **定期 push**，让云端始终有备份。
6. **善用 Issue** 记录"想做但还没做"的事。
