## 专题 4 · 🌐 用 GitHub 做在线简历 / 作品集

**适合谁**：求职者、自由职业者、想有个"网上门面"的人。

**为什么用 GitHub**：
- **免费、永久在线**，一个网址走天下，比 PDF 简历更现代。
- 随时更新，不用重新发文件给别人。
- 对技术岗，**GitHub 主页本身就是作品集**——招聘方会看。

**怎么一步步做**：

1. 建仓库 `你的用户名.github.io`（用户站点，[第 09 章](../09-用GitHub-Pages免费建网站.md)）。
2. 放一个 `index.html`，下面是**可直接抄的简历模板**：

```html
<!DOCTYPE html>
<html lang="zh">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>李小明 · 简历</title>
  <style>
    body{font-family:system-ui,sans-serif;max-width:720px;margin:50px auto;padding:0 20px;line-height:1.8;color:#1f2937}
    h1{margin-bottom:0}.sub{color:#6b7280}h2{border-bottom:2px solid #2563eb;padding-bottom:6px;color:#2563eb}
    .item{margin:14px 0}.tag{display:inline-block;background:#eff6ff;color:#2563eb;padding:2px 10px;border-radius:99px;font-size:13px;margin:2px}
  </style>
</head>
<body>
  <h1>李小明</h1>
  <p class="sub">📧 lixiaoming@example.com ｜ 🔗 github.com/lixiaoming ｜ 📍 北京</p>

  <h2>关于我</h2>
  <p>一名热爱学习的[你的身份]，擅长[你的强项]，正在寻找[目标岗位]机会。</p>

  <h2>技能</h2>
  <p>
    <span class="tag">Git/GitHub</span><span class="tag">Python</span>
    <span class="tag">数据分析</span><span class="tag">英语流利</span>
  </p>

  <h2>项目经历</h2>
  <div class="item"><b>个人学习笔记库</b>（github.com/lixiaoming/my-notes）<br>用 GitHub 管理，已积累 50+ 篇笔记。</div>

  <h2>教育</h2>
  <div class="item"><b>某某大学</b> · 某某专业 · 2022–2026</div>
</body>
</html>
```

3. 提交后访问 `https://你的用户名.github.io`，简历就上线了。把网址放进求职邮件、社交资料。

**进阶点子**：
- 想要现成漂亮模板：搜 GitHub 上的 `resume template`、`portfolio template`，Fork 一个改成你的。
- 配合**专题 6 的习惯打卡**，让你的贡献热力图常年翠绿，招聘方一看就知道你持续在学。
- 做一张主页"个人名片"（[第 10 章](../10-美化主页与Markdown进阶.md)），双管齐下。

> 🔑 核心收获：一份**永远在线、随时更新、还顺便展示你 GitHub 活跃度**的简历。

## 专题 5 · ✅ 用 Issues + Projects 管理待办与项目

**适合谁**：想用专业工具管理自己学习/生活/副业的人。

**为什么用 GitHub**：
- **Issue** 就是天然的"任务工单"，能分类、讨论、追踪。
- **Projects** 是看板（待办 / 进行中 / 完成），拖拖卡片管进度。
- 全程免费，比很多待办 App 还强，还和你的代码/笔记在一起。

**怎么一步步做**：

1. 建一个仓库当"项目中枢"，比如 `my-life-projects`。
2. **用 Issue 记每件要做的事**：
   - **Issues → New issue**，标题 `读完《原则》并写笔记`。
   - 正文用**任务清单**拆解：
     ```markdown
     - [x] 读完第一部分
     - [ ] 读完第二部分
     - [ ] 写读书笔记
     ```
   - 这些方框在 Issue 里**能直接点击打勾**，进度可视化。
3. **用 Label 分类**：给 Issue 贴 `学习`、`副业`、`紧急` 等标签（Issues → Labels 自定义）。
4. **用 Projects 做看板**：仓库 **Projects → New project → Board**，建"待办 / 进行中 / 完成"三列，把 Issue 拖进去，做到哪拖到哪。

**进阶点子**：
- 用 **Milestone** 设阶段目标（如"3 月底前学完 Git"），把相关 Issue 归进去看完成度。
- 周末花 10 分钟"整理看板"，仪式感拉满，坚持更容易。

> 🔑 核心收获：**用工程师管理项目的方式管理你的人生**，把模糊的"我想做……"变成可追踪、有进度、会完成的具体任务。

## 专题 6 · 🔥 用每日 commit 做习惯打卡 / 学英语

**适合谁**：想培养习惯、需要外部督促的人。

**为什么用 GitHub（独特的激励机制）**：
- GitHub 主页有一张**贡献热力图**（绿格子日历），你**每天有提交，当天就变绿**。
- "**别断了连续记录**"的心理，是极强的坚持动力（类似 duolingo 的连胜）。

**怎么一步步做**：

1. 建仓库 `daily-english`（或 `habit-tracker`）。
2. **每天提交一次**，内容就是你今天的学习/打卡：
   - 学英语：建 `2026-06-12.md`，写今天学的 10 个单词、一个句子。
   - 健身/读书/任何习惯：在 `打卡.md` 里加一行 `2026-06-12 ✅ 跑步30分钟`。
3. **commit + push**，主页热力图当天就亮一格绿。
4. 坚持下去，看着热力图一天天变绿，成就感和压力会推着你不断。

```
贡献热力图（越绿提交越多，别让它断）：
  一 二 三 四 五 六 日
  🟩 🟩 🟩 ⬜ 🟩 🟩 🟩    ← 周四断了一天，会很想补上！
  🟩 🟩 🟩 🟩 🟩 🟩 🟩    ← 全勤一周，超有成就感
```

**进阶点子**：
- 把打卡和**专题 5 的 Issue 待办**结合，每天打卡时顺手更新任务进度。
- 用 [第 12 章 Actions](../12-GitHub-Actions自动化入门.md) 做个"连续打卡天数"自动统计（进阶）。

> 🔑 核心收获：把"坚持"这件反人性的事，**外包给一张让你不忍心弄断的绿格子日历**。顺便每天练手 Git。

## 专题 7 · 📝 零基础搭一个个人博客

**适合谁**：想写博客、又不想花钱买服务器/域名的人。

**为什么用 GitHub**：
- **GitHub Pages 免费托管**，写完推上去就自动发布成网站。
- 用 Markdown 写文章，专注内容，样式交给主题。

**怎么一步步做（两条路，从易到难）**：

**路线 A（最简单）**：用现成博客模板 Fork
1. 去 GitHub 搜一个新手友好的博客模板（搜 `jekyll blog theme` 或 `hexo theme`，挑 Star 多、README 清楚的）。
2. **Fork** 到自己账号，按它 README 的说明改成你的（改 `_config.yml` 里的名字、标题）。
3. 在 `_posts/` 文件夹里用 Markdown 写文章，commit + push，文章就发布了。

**路线 B（更自由）**：本地用框架生成
1. 选一个静态博客框架（**Hexo** / **Hugo** / **VitePress** 对中文友好）。
2. 按官方教程在本地初始化、写文章、生成静态文件。
3. 用 [第 12 章 GitHub Actions](../12-GitHub-Actions自动化入门.md) **自动构建 + 部署到 Pages**——你只管 `git push` 文章，剩下机器全包。

**进阶点子**：
- 绑定自己的域名（Settings → Pages → Custom domain），更专业。
- 评论功能可用 giscus（基于 GitHub Discussions）等免费方案。

> 🔑 核心收获：一个**零成本、你完全掌控、用 Git 管理**的个人博客，写作发布一气呵成。
