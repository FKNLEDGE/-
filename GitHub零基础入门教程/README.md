# 🐙 GitHub 零基础入门教程

> 一句话定义：**Git = 给文件装一个"带时光机的存档系统"；GitHub = 把这套存档放到云端，还能和别人一起改。**

这个教程是为**完全零基础**的人写的——没用过命令行、没写过代码、只知道"听说程序员都在用 GitHub"也没关系。我们不堆术语，而是从**你每天都会遇到的真实烦恼**（"文件改乱了找不回上一版""发给别人改完合并不回来"）出发，一步步讲清楚 Git 和 GitHub 到底解决了什么问题、怎么用。

学完你应该能：

- 看懂 GitHub 上一个项目页面里每个按钮、每个名词是什么意思；
- 自己建仓库、上传文件、改了能撤回、和别人协作；
- 给开源项目提交你的第一个 Pull Request（贡献代码）；
- 遇到红色报错不再慌——知道去哪查、怎么救。

## 🧭 一张图看懂 Git/GitHub 是怎么转的

```
        你的电脑（本地）                          GitHub（云端）
┌─────────────────────────────────┐      ┌──────────────────────────┐
│                                 │      │                          │
│  工作区        暂存区     本地仓库 │      │      远程仓库              │
│ (你正在改   (准备打包  (已存档的  │      │  (云端的备份+协作中心)     │
│  的文件)     的清单)    历史版本) │      │                          │
│    │           │          │     │      │          │               │
│    │  git add  │ git      │     │      │          │               │
│    ├──────────►│ commit   │     │      │          │               │
│    │           ├─────────►│     │ push │          │               │
│    │           │          ├─────┼──────┼─────────►│               │
│    │           │          │     │ pull │          │               │
│    │           │          │◄────┼──────┼──────────┤               │
│                                 │      │          │               │
└─────────────────────────────────┘      └──────────┼───────────────┘
                                                     │
                                         别人也能 clone / pull / push
                                         一起改这个项目
```

- **工作区**：你眼睛能看到、正在编辑的文件夹。
- **暂存区**：一个"待打包清单"，你挑出这次想保存哪些改动。
- **本地仓库**：你电脑上的"时光机存档库"，存着所有历史版本。
- **远程仓库（GitHub）**：云端的同一个库，既是备份，也是大家协作的中转站。

> 这四个方块 + `add/commit/push/pull` 四个动作，就是 80% 的日常操作。04 章会把它们彻底讲透。

## 🎯 给小白的 5 条心态建议

1. **别怕报错**。Git 的报错信息往往直接告诉你下一步该敲什么命令，看不懂就复制去搜——这是程序员的日常，不丢人。
2. **先会用，再求懂原理**。你不需要先理解"哈希""有向无环图"才能用 GitHub，就像不懂发动机也能开车。
3. **命令记不住很正常**。常用的就 7、8 条，[速查表](./08-命令速查表与术语表.md) 放手边，用多了自然记住。
4. **多用网页和 GitHub Desktop**。命令行不是必须的，图形界面一样能完成 90% 的事，[第 3 章](./03-第一个仓库（网页版）.md) 全程不用命令行。
5. **拿真项目练手**。建个仓库放你的读书笔记、照片清单、学习资料都行，用起来比看十遍教程都强。

---

*本教程面向初学者，命令与界面以各工具官方最新版本为准。GitHub 网页界面偶有改版，但本文讲的概念与命令长期稳定。*
