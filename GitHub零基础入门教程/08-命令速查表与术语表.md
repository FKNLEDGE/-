## 一、一页纸高频命令速查

### 🚀 配置（装好后只做一次）

```bash
git config --global user.name "你的名字"        # 设置提交用的名字
git config --global user.email "你的邮箱"        # 设置提交用的邮箱
git config --global init.defaultBranch main     # 默认分支叫 main
git config --global core.quotepath false        # 让中文文件名正常显示
git config --global --list                       # 查看当前配置
```

### 📥 开始一个项目

```bash
git clone <仓库地址>        # 把云端仓库下载到本地（最常用）
git init                    # 把当前文件夹变成一个 Git 仓库（从零开始时用）
```

### 🔁 日常核心循环（口诀：拉、改、加、提、推）

```bash
git pull                    # ① 干活前先拉最新
#   ...改你的文件...         # ②
git status                  # 随时看现在什么情况（养成习惯！）
git add .                   # ③ 把所有改动放进暂存区
git commit -m "提交说明"     # ④ 存档 + 留言
git push                    # ⑤ 上传到 GitHub
```

### 🌿 分支

```bash
git branch                  # 看所有分支
git switch -c <分支名>       # 新建并切换到分支
git switch <分支名>          # 切到已有分支
git merge <分支名>           # 把指定分支合并进【当前】分支
git branch -d <分支名>       # 删除分支
git push -u origin <分支名>  # 把分支推到 GitHub
```

### 🔍 看历史 / 看差异

```bash
git log --oneline           # 简洁列出提交历史（按 q 退出）
git log --oneline --graph   # 带分支图的历史
git diff                    # 看还没 add 的改动
git show <提交ID>            # 看某次提交具体改了啥
```

### ⏪ 后悔药（详见第 7 章）

```bash
git restore <文件>                  # 丢弃工作区改动（还没add）
git restore --staged <文件>         # 把文件撤出暂存区（已add未commit）
git commit --amend -m "新说明"      # 改最后一次提交（没push时）
git reset --soft HEAD~1             # 撤销最近一次提交，保留改动
git revert <提交ID>                 # 安全地撤销一次【已push】的提交
git reflog                          # 终极后悔药：找回"丢失"的提交
git merge --abort                   # 放弃正在进行的合并
```

## 二、命令"翻译对照表"（看到命令秒懂在干嘛）

| 命令 | 大白话 |
| --- | --- |
| `clone` | 把云端仓库**整个下载**到电脑 |
| `add` | 把改动**挑进纸箱**（暂存区） |
| `commit` | **封箱存档**并写一句说明 |
| `push` | 把存档**寄到** GitHub |
| `pull` | 把 GitHub 的更新**取回**本地 |
| `status` | "现在**什么情况**？" |
| `log` | "都**改过哪些**？"（历史） |
| `diff` | "这次到底**改了哪几行**？" |
| `branch` | 管理**分身**（分支） |
| `switch` | **切换**到某个分身 |
| `merge` | 把分身的成果**合并**回来 |
| `restore` | **还原**改动 |
| `reset` | **退回**到某个版本 |
| `revert` | 用**反向提交**抵消某次改动 |
| `fork`（网页操作） | 把别人的仓库**抄一份**到自己账号 |

| 克隆 | Clone | 把仓库下载到本地 |

| 忽略文件 | .gitignore | 列出"不让 Git 管"的文件 |

## 四、最常用的 8 条命令（背下这些就够日常）

如果你只想先记住最少的东西，就记这 8 条：

```
1. git clone <地址>      —— 下载项目
2. git pull              —— 拉最新
3. git status            —— 看情况
4. git add .             —— 加改动
5. git commit -m "..."   —— 存档
6. git push              —— 传上去
7. git switch -c <名>    —— 开分支
8. git merge <名>        —— 合分支
```

> 90% 的日常工作就是这 8 条在转。其余的用到了再查本表。

## 五、推荐继续学习的资源

> 📚 这里是精简版。**完整的"外部优质资源精选 + 和本教程怎么分工"在 [31-延伸资源精选](./31-延伸资源精选-站在巨人肩上.md)**——按"互动游戏/官方文档/中文教程/救急/速查/规范/视频/工具"分好类，每个都注明中文友好度和适用场景。

### 📖 交互式 / 可视化（强烈推荐小白）

- **Learn Git Branching**（learngitbranching.js.org）：**中文可切换**，用动画+闯关教分支，号称"学 Git 最好的网站"，一定要玩一遍。
- **GitHub Skills**（skills.github.com）：GitHub 官方互动课程，在真实仓库里边做边学。

### 📚 文档 / 书（系统查阅）

- **Pro Git（中文版）**：git-scm.com/book/zh/v2 —— 官方圣经，免费，需要深入时来查。
- **GitHub 官方文档（中文）**：docs.github.com/zh —— 任何 GitHub 功能的权威说明。
- **廖雪峰 Git 教程**：中文社区流传很广的入门教程，例子接地气。

### 🛠️ 工具

- **GitHub Desktop**（desktop.github.com）：官方图形界面，不爱命令行就用它。
- **VS Code**：内置 Git 面板，写代码 + 版本管理一站搞定，对新手非常友好。
- **GitHub CLI（gh）**：在命令行里直接建仓库、提 PR，熟练后效率很高。

### 🌏 国内备选

- **Gitee（码云）** gitee.com：访问快、界面中文，练手时 GitHub 卡可以用它，操作一模一样。

## 🎓 结业寄语

读到这里，你已经走完了从"GitHub 是什么"到"给开源项目提 PR"的完整路径。但**真正学会 Git/GitHub 的唯一方法是用它**：

1. **今天就建一个仓库**，哪怕只放你的读书笔记、菜谱、追剧清单。
2. **坚持用"分支 + PR"的方式**给自己的项目干活，把肌肉记忆练出来。
3. **去玩一遍 Learn Git Branching**，把分支彻底搞懂。
4. **找个 `first-contributions` 项目提个 PR**，体验一次真实贡献。

遇到不懂的，回来查这八篇就好。祝你玩得开心，欢迎来到开源世界 🐙🎉
