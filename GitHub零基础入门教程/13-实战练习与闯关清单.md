## 二、闯关任务（从易到难，循序渐进）

### 🥉 青铜关：一个人玩通基础流程

**任务 1 · 建个"学习追踪"仓库**
> 练：03、04、10

1. 建仓库 `learning-log`，README 里用 Markdown 写一个**任务清单**（`- [ ]`）列出你想学的 5 样东西。
2. clone 到本地，每"学完一样"就把对应的 `- [ ]` 改成 `- [x]`，commit（信息写清楚学了啥）+ push。
3. 连续做 3 天，去提交历史看你的"学习足迹"。

**任务 2 · 玩通关 Learn Git Branching**
> 练：05

打开 **learngitbranching.js.org**（右上角可切中文），把"主线"关卡全部通关。这是把分支彻底搞懂的最快方式，**强烈建议人人都过一遍**。

---

### 🥈 白银关：分支与撤销实战

**任务 3 · 分支开发一个小功能**
> 练：05

1. 在 `learning-log` 里，从 `main` 开分支 `add-resources`。
2. 在分支上新建 `资源链接.md`，写几个学习网站，commit。
3. 切回 `main` 确认看不到这个文件，再把分支合并回 `main`，最后删掉分支。

**任务 4 · 故意闯祸，再用后悔药救回来**
> 练：07

1. 故意 `git commit` 一个写错的提交信息，用 `--amend` 改正。
2. 故意改乱一个文件不提交，用 `git restore` 还原。
3. （进阶）故意 `git reset --hard` 删掉一个提交，再用 `git reflog` 找回来。
4. 体会"Git 里几乎什么都能救回来"的安心感。

**任务 5 · 制造并解决一次冲突**
> 练：05、11

在两个分支里改同一个文件的同一行，合并，**亲手解决冲突**。先用命令行删标记的方式做一次，再用 VS Code 的按钮做一次，对比体验。

---

### 🥇 黄金关：真实协作与开源

**任务 6 · 提交人生第一个开源 PR**
> 练：06

去 GitHub 搜 **first-contributions**（专门给新人练手的超有名项目，README 手把手教你），**完整走一遍 Fork → Clone → 改 → push → 提 PR**。你的名字会被合并进一个全球新人贡献墙，很有纪念意义。

**任务 7 · 和朋友合作一个仓库**
> 练：05、06

1. 拉一个朋友/同学，把对方加成仓库 **Collaborator**。
2. 两人各开各的分支改不同文件，分别提 PR，**互相 Review** 后再合并。
3. 故意让两人改同一处，体验团队里冲突是怎么产生和解决的。

---

### 👑 王者关：综合作品（毕业项目）

**任务 8 · 做一个"完整的"个人项目**
> 练：09、10、12 全部串起来

做一个你的**个人主页网站 + 漂亮的项目门面**，集齐：

- [ ] 用 **GitHub Pages** 上线一个 `用户名.github.io` 网站（09）
- [ ] 做一张主页 **个人名片**（用户名同名仓库 + 进阶 Markdown）（10）
- [ ] README 里放 **徽章、表格、折叠块、Mermaid 图**（10）
- [ ] 配一个 **GitHub Actions** 工作流，README 顶部挂一个**状态徽章**（12）
- [ ] 整个项目用**分支 + PR** 的方式开发，而不是直接推 main（05、06）

做完这个，你就把这套教程的所有核心技能**用在了一个真实作品上**——这本身就是一份能放进简历的成果。

## 三、练手项目点子（不知道做啥时挑一个）

| 项目 | 练到什么 | 难度 |
| --- | --- | --- |
| 📒 读书/观影/菜谱清单仓库 | Markdown、日常提交、表格 | ⭐ |
| 🌐 个人主页 / 在线简历 | Pages、HTML、Markdown | ⭐⭐ |

> 🔑 **最好的练手项目，是你真的会用的那个**。哪怕只是记账单、存照片清单——只要你**持续用**，技能自然就长进身体里了。

## 四、坚持下去的小建议

1. **每天一次小提交**：哪怕只是改一行笔记。连续提交会在你主页生成绿色的"贡献热力图"，看着它一天天变绿，很有动力。
2. **强迫自己用分支 + PR**：哪怕一个人的项目也这么干，把专业习惯练成本能。
3. **遇错就查、就搜**：把第 7 章当字典，报错复制去搜，这是程序员的日常。
4. **教是最好的学**：把你学会的，写成笔记发出来 / 教给朋友，你会发现哪里其实没懂。

## ✅ 结业标准

当你能**不看教程**独立完成下面这串操作，就算正式出师了：

> clone 一个项目 → 开分支 → 改代码 → 提交 → 推送 → 提 PR → 被要求修改后继续提交 → 合并 → 处理一次冲突 → 给项目配一张 README 徽章。

做得到，恭喜你 🎓——欢迎正式加入开源世界，去 GitHub 上探索、贡献、建造属于你的东西吧 🐙🚀
