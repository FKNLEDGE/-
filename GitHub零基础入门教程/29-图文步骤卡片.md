# 29 · 图文步骤卡片（用界面示意图精确告诉你"点哪里")

> 没有真实截图，但我用**文字画出每个界面的样子**，并用 `← 点这里` 精确标出每一步点哪、填啥。把它当"配图版操作手册"，照着界面对位置就行。
> 每张卡片 = 一个高频操作。界面可能随 GitHub 改版略有不同，但**位置和文字关键词长期稳定**。

> 🧭 图例：`[按钮]` 表示可点的按钮；`▾` 表示下拉菜单；`← 点这里` / `← 填这里` 是给你的指引。

## 卡片 1 · 在网页上新建仓库

```
GitHub 任意页面，右上角：
                                          ┌──────────────┐
   ......  🔍搜索框   [➕▾] ← 点这个加号   │ New repository│ ← 点这一项
                      [👤▾头像]            │ Import...     │
                                          │ New gist      │
                                          └──────────────┘

进入新建表单：
┌─────────────────────────────────────────────────────┐
│ Create a new repository                              │
│                                                      │
│ Owner          Repository name                       │
│ [你的用户名▾] / [my-notes        ] ← 填仓库名(英文)   │
│                                                      │
│ Description (optional)                                │
│ [我的笔记                        ] ← 选填，一句话简介  │
│                                                      │
│ ◉ Public   ← 公开(谁都能看)，学习选这个               │
│ ○ Private  ← 私有(只你能看)，含隐私选这个              │
│                                                      │
│ ☑ Add a README file  ← ✅一定勾上！仓库才不为空        │
│ Add .gitignore: [None▾]   ← 暂时不用动                │
│ Choose a license: [None▾] ← 暂时不用动                │
│                                                      │
│          [ Create repository ] ← 最后点这个绿钮        │
└─────────────────────────────────────────────────────┘
```

## 卡片 2 · 仓库主页认门（每个区域是啥）

```
┌───────────────────────────────────────────────────────────────┐
│ 🔱 你的用户名 / my-notes              [👁Watch][🍴Fork][⭐Star]  │ ← 仓库名+互动
├───────────────────────────────────────────────────────────────┤
│ [<>Code] [⊙Issues] [⟳Pull requests] [▶Actions] ... [⚙Settings] │ ← 功能标签页
├───────────────────────────────────────────────────────────────┤
│ 🌿[main▾] ←分支    [⏱ 5 commits] ←点这看历史   [<>Code▾] ←下载/克隆│
│                                                                │
│  📁 docs                          上次提交说明      2 天前       │ ← 文件/文件夹列表
│  📄 README.md                     初始化           5 天前       │
│  📄 日记.md                        新增日记          1 小时前     │
│ ───────────────────────────────────────────────────────────── │
│  📖 README.md 的内容会自动显示在下面：                           │
│     # my-notes                                                 │
│     我的笔记                                                    │
└───────────────────────────────────────────────────────────────┘
```
> 🔑 记住三个最常用：**绿色 `<>Code▾`**(下载/克隆)、**`[⏱ X commits]`**(看历史)、**`🌿main▾`**(切分支)。

## 卡片 3 · 在网页上编辑文件并提交

```
① 点开文件(如 README.md)后，文件右上角一排小图标：
                                    ┌─────────────────────────┐
   Raw  Blame  ...  [✏️] [⋯]        │ ✏️ = Edit this file 编辑 │ ← 点铅笔
                     ↑点这个铅笔     └─────────────────────────┘

② 进入编辑界面，上方有两个标签：
   [ Edit ] [ Preview ]  ← Edit 改内容，Preview 看排版效果
   ┌───────────────────────────────────────┐
   │ # 我的笔记                              │ ← 在这里打字修改
   │ 今天学了 GitHub！                       │
   └───────────────────────────────────────┘

③ 改完，点右上角绿色按钮：
   [ Commit changes... ] ← 点它，弹出提交框

④ 提交框：
   ┌──────────────────────────────────────┐
   │ Commit message                       │
   │ [完善README，加了一句               ] │ ← 填：这次改了啥
   │ Extended description (optional)       │
   │ [                                  ] │ ← 可留空
   │                                       │
   │ ◉ Commit directly to the main branch  │ ← 选这个
   │ ○ Create a new branch...              │
   │                                       │
   │         [ Cancel ]  [ Commit changes ]│ ← 点绿色这个，完成！
   └──────────────────────────────────────┘
```

## 卡片 4 · 复制克隆地址（准备 clone 到本地）

```
仓库主页，点绿色 [<>Code▾] 按钮，弹出：
┌─────────────────────────────────────────────┐
│ [Local] [Codespaces]                         │
│                                              │
│ Clone                                        │
│ ( HTTPS )( SSH )( GitHub CLI ) ← 选哪个见下   │
│ ┌─────────────────────────────────────┐ 📋  │
│ │ https://github.com/你/my-notes.git  │ ←点📋│
│ └─────────────────────────────────────┘ 复制 │
│                                              │
│ ⬇ Download ZIP  ← 只想要文件、不同步就点这    │
└─────────────────────────────────────────────┘

选哪个地址？
  • 配了 PAT 令牌 → 选 [HTTPS]
  • 配了 SSH 密钥 → 选 [SSH]   (见第 02 章)
  点右边 📋 图标复制地址，到终端 git clone <粘贴>
```

## 卡片 5 · Fork 一个别人的项目

```
别人的仓库主页，右上角：
   [👁Watch ▾]  [🍴Fork ▾]  [⭐Star ▾]
                   ↑ 点 Fork

弹出 Create a new fork：
┌──────────────────────────────────────┐
│ Owner          Repository name        │
│ [你的用户名▾] / [项目名            ]  │ ← 一般默认即可
│ ☑ Copy the main branch only           │ ← 默认勾着就行                   │
│           [ Create fork ] ← 点这个     │
└──────────────────────────────────────┘
稍等几秒 → 你账号下就有了一份副本 github.com/你/项目名
```

## 卡片 6 · 发起一个 Pull Request

```
① 你 push 完分支后，仓库页常自动出现黄条：
┌──────────────────────────────────────────────────┐
│ 🟡 fix-typo had recent pushes                      │
│              [ Compare & pull request ] ← 点这个    │
└──────────────────────────────────────────────────┘
（没看到黄条就点 [⟳Pull requests]标签 → [New pull request]绿钮）

② 进入 PR 创建页，先确认方向(箭头)：
   base: [原作者/项目:main▾]  ◄── compare: [你/项目:fix-typo▾]
        (要合并进的目标)            (你的改动来源)

③ 填标题和说明：
   ┌──────────────────────────────────────┐
   │ Title: [修正README拼写错误         ] │ ← 一句话标题
   │ ┌──────────────────────────────────┐ │
   │ │ 第3段 recieve 应为 receive。      │ │ ← 说清改了啥、为啥
   │ │ Closes #5                         │ │ ← (可选)关联Issue
   │ └──────────────────────────────────┘ │
   │        [ Create pull request ] ← 点绿钮│
   └──────────────────────────────────────┘
```

## 卡片 7 · 在 PR 里逐行评论（代码审查）

```
PR 页面点 [Files changed] 标签，看到逐行 diff：
┌────────────────────────────────────────────┐
│ README.md                                   │
│   1   # 项目说明                             │
│ + 2   这是一个很棒的项目        ← 绿色=新增   │
│ - 3   这是个项目              ← 红色=删除    │
│   4                                         │
│   把鼠标移到某一行最左边，会冒出一个 [➕]     │
│   点 [➕] → 弹出评论框，针对这一行提意见      │
│   ┌────────────────────────────┐            │
│   │ 这句建议改得更具体一点         │            │
│   │   [Add single comment] [Start a review]│ │
│   └────────────────────────────┘            │
└────────────────────────────────────────────┘
```

```
PR 的 [Conversation] 标签，底部：

│ ✅ All checks have passed   ← 自动测试都过了    │
│ ✅ This branch has no conflicts                │
```

## 卡片 9 · 开启 GitHub Pages（把仓库变网站）

```

┌──────────────────────────────────────────────┐
│ GitHub Pages                                  │
│                                               │
│ Source                                        │
│ [ Deploy from a branch ▾ ] ← 选这个            │
│                                               │
│ Branch                                        │
│ [ main ▾ ]  [ / (root) ▾ ]  [ Save ] ← 选main、│
│                                根目录，点Save  │
│                                               │
│ (保存后等1-3分钟，这里会显示：)                 │
│ ✅ Your site is live at https://...   [Visit site]│
└──────────────────────────────────────────────┘
```

## 卡片 10 · 找设置入口（改语言、改公开性、删库）

```
仓库页 → [⚙Settings]（在最右边的标签）：

改成中文：
   头像▾ → Settings(账号设置,不是仓库的) → 左侧[Appearance] → Language → 简体中文

改公开/私有 & 删库：
   仓库的 Settings → 一直拉到最底部
   ┌──────────────── ⚠️ Danger Zone ────────────────┐
   │ Change repository visibility  [Change visibility]│ ← 改公开/私有
   │ Delete this repository        [Delete]           │ ← 删库(不可逆!)
   └─────────────────────────────────────────────────┘
   ⚠️ 这个区域操作不可逆，看清再点
```

## 🧭 怎么用这一篇

- **第一次做某操作时**：打开对应卡片，对照你屏幕上的界面，一个位置一个位置地点。
- **界面对不上**？GitHub 偶尔改版，但**按钮上的英文关键词**（如 `Commit changes`、`Pull requests`、`Settings`、`Pages`）长期不变，**认文字找位置**就行。
- 想知道每步**背后在干嘛**，点回对应正文章节（卡片里都提到了章号）。
