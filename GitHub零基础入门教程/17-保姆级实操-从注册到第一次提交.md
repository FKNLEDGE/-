# 17 · 保姆级实操：从注册到第一次提交（每一步、每个画面都写给你）

> 前面的章节是"讲明白原理"，这一篇是"**拉着你的手走一遍**"。我会把**每一次点击、每一个你会看到的画面、每一个要填的框**都写出来，你照着做就行。
> 目标：跟完这一篇，你将**从零**完成人生第一次提交，并把它传上 GitHub。预计 30 分钟。

---

## 开始前你需要

- 一台能上网的电脑（Windows 或 Mac 都行）；
- 一个常用邮箱；
- 30 分钟，和"我一定能搞定"的心态 💪。

> 我们这一篇**全程用网页操作，不碰命令行**，确保零基础也能 100% 走通。命令行版本在第 04 章，等你想"在自己电脑上干活"时再去。

---

## 第一幕：注册账号（约 5 分钟）

### 步骤 1：打开注册页

浏览器地址栏输入 **github.com**，回车。看到 GitHub 首页后，点**右上角的 `Sign up`** 按钮。

> 📺 你会看到一个让你填邮箱的页面。

### 步骤 2：按提示一步步填

GitHub 现在是"一问一答"式注册，跟着填：

1. **Enter your email**（输入邮箱）→ 填你的常用邮箱 → 点 **Continue**。
2. **Create a password**（设置密码）→ 输一个**至少 8 位、含字母和数字**的密码 → **Continue**。
3. **Enter a username**（取用户名）→ ⚠️ **重要**：这会变成你的网址 `github.com/这个名字`，相当于门牌号，**以后改起来麻烦**。
   - 建议：简洁的英文，如 `lixiaoming`、`xm-li`。
   - 如果提示 `Username is not available`（名字被占了），换一个，或加点数字。
   - 填好 → **Continue**。
4. 可能会问 **是否接收产品更新邮件**，输 `y`（要）或 `n`（不要）都行 → **Continue**。

### 步骤 3：证明你是人类

会出现一个**小游戏式的验证**（比如"旋转图片让动物正立""选出对应的图形"）。按提示点几下，完成。

> 📺 卡在这一步很常见，多试几次、看清提示文字即可。

### 步骤 4：去邮箱收验证码

GitHub 会往你刚填的邮箱发一封带**验证码（launch code）**的邮件。

1. 打开你的邮箱，找到来自 GitHub 的邮件（**收件箱没有就翻垃圾邮件/广告箱**）。
2. 看到一个 **8 位数字** → 回到 GitHub 页面把它填进去。

✅ 填对后，账号就创建成功了！你会进入 GitHub 的欢迎/设置页面，可能会问你"用来做什么、团队多大"之类，**随便选或直接跳过（Skip）都行**。

### 步骤 5（强烈建议现在就做）：把界面改成中文

1. 点**右上角你的头像** → 下拉菜单点 **Settings（设置）**。
2. 左侧菜单找到 **Appearance（外观）**。
3. 找到 **Language** 区域，把语言选成 **简体中文** → 保存。

> 📺 之后大部分界面就是中文了，看着亲切很多。（本教程仍用中英对照，方便你两边都认得。）

## 第二幕：建第一个仓库（约 5 分钟）

### 步骤 6：点"新建仓库"

页面**右上角有个 `➕` 号**，点它 → 选 **New repository（新建仓库）**。

> 📺 你会进入一个填表页面。别被一堆选项吓到，下面告诉你每个填啥。

### 步骤 7：填仓库信息

| 你看到的框 | 填什么 | 说明 |
| --- | --- | --- |
| **Repository name**（仓库名）| `my-first-repo` | 用英文/数字/连字符，**别用空格和中文** |
| **Description**（描述）| `我的第一个仓库` | 一句话简介，**选填**，留空也行 |
| **Public / Private** | 点选 **Public（公开）** | 学习用公开就好；公开≠别人能改你的，只是能看 |
| **Add a README file** | ✅ **一定要勾上！** | 勾了它会自动生成一个文件，仓库才不是空的，后面才好操作 |
| Add .gitignore | **不用动**，保持 None | 以后再说（第 04 章） |
| Choose a license | **不用动**，保持 None | 以后再说（第 19/术语） |

### 步骤 8：创建

拉到页面底部，点绿色的 **Create repository（创建仓库）** 按钮。

🎉 **你的第一个仓库诞生了！** 你会跳转到仓库主页，网址是 `github.com/你的用户名/my-first-repo`。

> 📺 你现在看到的画面：上方是仓库名和几个标签（Code / Issues / Pull requests…），中间是一个文件列表，里面有一个 `README.md`，下方自动显示着 README 的内容（现在就一行仓库名）。

## 第三幕：完成你的第一次提交（约 10 分钟）

我们来**修改这个 README**，亲历一次"提交（commit）"。

### 步骤 9：打开 README 进入编辑

1. 在文件列表里，**点一下 `README.md`** 这个文件名。
2. 进入文件查看页后，找到**右上角一个铅笔图标 ✏️**（鼠标悬停会显示 `Edit this file`）→ 点它。

> 📺 现在你进入了一个**文本编辑界面**，上半部分能打字，里面已经有一行 `# my-first-repo`。

### 步骤 10：把内容换成你的

把编辑框里的内容**全选删掉**，粘贴下面这段（改成你自己的信息）：

```markdown
# 我的第一个仓库 🎉

你好！这是我在 GitHub 上的第一个仓库。

## 关于我
- 👋 我叫小明
- 🌱 我正在学习使用 Git 和 GitHub
- 🎯 我的目标：学会用 GitHub 管理我的学习笔记

## 我的第一次提交
今天是 **2026 年某月某日**，我完成了人生第一次 commit！
```

> 💡 不懂 `#`、`**` 是什么？那是 **Markdown 排版语法**——`#` 是大标题，`**xx**` 是加粗。详见第 03、10 章。现在照抄即可。

### 步骤 11：预览一下效果（可选但推荐）

编辑框上方有两个标签：**Edit（编辑）** 和 **Preview（预览）**。点 **Preview**，能看到你写的东西**排版后长什么样**（标题变大、星号变成加粗）。点回 Edit 继续改。

### 步骤 12：提交（关键时刻！）

1. 点编辑页**右上角的绿色按钮 `Commit changes...`**（提交更改）。
2. 会弹出一个小窗，这就是**填写提交信息**的地方：

```
┌─ Commit changes ─────────────────────────────┐
│  Commit message                              │
│  ┌──────────────────────────────────────┐   │
│  │ 完善 README，介绍我自己          ← 填这 │   │
│  └──────────────────────────────────────┘   │
│  Extended description（可留空）               │
│                                              │
│  ◉ Commit directly to the main branch        │ ← 选这个
│  ○ Create a new branch...                    │
│                                              │
│         [ Cancel ]   [ Commit changes ]      │ ← 点绿色这个
└──────────────────────────────────────────────┘
```

- **Commit message**：用一句话说清你干了啥，比如 `完善 README，介绍我自己`。
- 下面选 **Commit directly to the main branch**（直接提交到 main 分支）。
- 点绿色 **Commit changes**。

🎉🎉 **恭喜！你完成了人生第一次 commit！** 页面跳回仓库主页，README 已经变成你写的样子了。

---

## 第四幕：看见你的"足迹"（约 5 分钟）

### 步骤 13：查看提交历史

回到仓库主页，在文件列表的**右上方**，找到一个**带时钟图标、写着 `X Commits`（X 次提交）** 的地方，点它。

> 📺 你会看到一个**提交历史列表**，至少有两条：
> ```
> ● 完善 README，介绍我自己      你, 刚刚
> ● Initial commit                你, 几分钟前
> ```
> 这就是你的"足迹"！第一条是你刚做的，第二条是建仓库时自动产生的。

### 步骤 14：看看"到底改了哪几行"

**点一下**你那条 `完善 README...` 的提交记录。

> 📺 你会看到一个**对比画面**：
> - **绿色、前面带 `+`** 的行 = 你**新增**的内容；
> - **红色、前面带 `-`** 的行 = 被**删除**的内容。
>
> 这就是第 01 章说的"时光机"——每次改动都被清清楚楚记下来，再也不用 `最终版_真的最终.doc` 了。

### 步骤 15（额外成就）：上传一个文件

想把电脑里现成的文件（一张图、一个文档）放进来？

1. 回仓库主页，点 **`Add file ▾`（添加文件）→ `Upload files`（上传文件）**。
2. 把文件**直接拖进**虚线框里。
3. 下方填提交信息，如 `上传我的第一张图片`。
4. 点 **Commit changes**。

文件就进仓库了，同样留下一条历史记录。
